# JoeLang Studio

A focused static browser IDE for JoeLang. It includes an editable file tree, compact diagnostics, a syntax-aware editor, and a hideable runtime inspector with the generated JavaScript transcript.

Studio loads the portable [JoeLang Language Pack](../joelang-language-pack/) at startup. The pack owns keywords, diagnostics, formatting, projection, templates, and execution; this site owns the workspace UI. A compatible language-pack release can therefore extend Studio without a Studio UI release.
